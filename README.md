# Point business hebdo — app Miro

App Miro (Web SDK) du point business hebdomadaire Weinmann : panneau de saisie des dossiers,
rangement automatique par pilote (zone 1), priorités synchronisées (zone 2), compteurs calculés.

Ce dépôt ne contient que le code. Aucune donnée : les dossiers vivent uniquement dans le board Miro.
